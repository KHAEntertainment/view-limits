(https://github.com/lobehub/lobe-icons).

## Changes from upstream

- Files renamed to the dashboard's provider keys (`kimi.svg`, `glm.svg`, ...).
- `kimi`, `glm`, `minimax`, `deepseek`, `openrouter`, `alibaba` and `stepfun`
  are the upstream `*-color.svg` variants, byte-identical apart from the name.
- `xiaomi.svg` is upstream `xiaomimimo.svg` with the root `fill` changed from
  `currentColor` to Xiaomi orange (`#FF6900`), so the mark stays visible in
  both the light and dark page themes.
